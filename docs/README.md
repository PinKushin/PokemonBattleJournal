# Pokemon Battle Journal

A .NET MAUI app for logging and analyzing **Pokemon TCG** battle records.

## Quick start

```powershell
dotnet build PokemonBattleJournal.slnx
dotnet run --project PokemonBattleJournal/PokemonBattleJournal.csproj -f net9.0-windows10.0.19041.0
```
